# 魔改momo

原版拆分可见：[墨奇码表](https://github.com/gaboolic/moqima-tables)
上游拆分可见：[momo码表](https://github.com/yuanz-12/momo)

## 主要改动

### 字根改动
1. 新增字根"番"，这个字首字母是f，自然位于f。
> 例: "翻"由`mx`改为`fx`，与拆“爫”的字离散。

2. 字根“囗”移动到o键上（因为像o）。
> 例：“圆”由`wb`改为`ob`，与“员”等字三码离散。

> ps：哪些字拆出“口”哪些字拆出“囗”以原版墨奇码拆分表为准，例如“西”在原版墨奇码中末形为“口”。

3. 移除"釆"字根，原来momo首形拆"釆"的字改拆“爫”，原来末形拆"釆"的字改拆"米"。
> 例: "悉"又`mx`改为`vx`。

### 单字改动

1. 曲由`wc，囗艹`改为`co，艹囗`。

2. 嘛由`ka，口木`改为`kl，口林`。

3. 日由`wa，囗一`改为`ka，口一`。

4. 目由`we，囗二`改为`ke，口二`。

5. 番由`mt，釆田`改为`vo，爫曰`。

6. 田由`wu, 囗十`改为`ku，口十`。


### 兼容码改动

1. 移除“曲”“典”二字兼容码

2. 将“甩”的兼容码`ov，月乚`扶正，保留第一兼容码`kv，冂乚`的位置，将原墨奇码正拆`yv，用乚`降为第二位兼容码。
